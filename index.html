How to Deploy This Form

To deploy this form to GitHub Pages:

  1. Copy this entire HTML code
  2. Create a new GitHub repository named criteria-weighting
  3. Create a file named index.html in the repository
  4. Paste this code into the file and commit
  5. Go to Settings > Pages, select "main" branch, and save

Your form will be available at: https://.github.io/criteria-weighting

Note: The PDF generation works in the deployed version. This is just a frontend demo - in production, the PDF would be sent to the hardcoded email address.
